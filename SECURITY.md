# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.2.x   | :white_check_mark: |
| 2.1.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

We take the security of the **Omnichannel AI Voice Receptionist** platform very seriously. If you discover a security vulnerability or credential leak, please report it privately:

1. **Email**: Send details to `security@kishor.tech` or `kishor@kishor.tech`.
2. **Details to Include**:
   - Description of the vulnerability and affected endpoints.
   - Proof-of-concept script or reproduction steps.
   - Potential impact on telephony (Vapi/Twilio), OAuth tokens, or database integrity.

Please **do not** report security vulnerabilities via public GitHub issues.

We will acknowledge your report within 24 hours and provide an estimated resolution timeline.
