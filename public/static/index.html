📖 How to obtain your Meta Keys in 3 steps
  1. Create Meta App: Go to developers.facebook.com → Create App → Select Business type.
  2. Add Products: In the App Dashboard, add WhatsApp, Messenger, and Instagram Graph API.
  3. Generate Permanent Token: Go to Business Manager → System Users → Create an Admin System User → Click Generate New Token with permissions: pages_messaging, instagram_manage_messages, whatsapp_business_messaging.
  4. Copy IDs: Copy the Phone Number ID from WhatsApp > API Setup, your Facebook Page ID, and Instagram ID.
