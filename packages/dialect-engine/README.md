# Voice Dialect Engine (`voice-dialect-engine`)

Acoustic and lexical regional dialect adaptation engine with zero-overhead persona switching.

## Supported Dialects & Accents
- `american_general`: US Standard English (Warm, professional)
- `uk_rp`: British English (Polite, articulate)
- `indian_english`: Clear, courteous Indian cadence with cultural greeting tokens ("Namaste!")
- `hispanic_latino`: Warm, expressive bilingual English/Spanish cadence
- `southern_us`: Hospitality-forward, relaxed Southern drawl
- `australian`: Friendly, upbeat Australian cadence
- `aave`: Modern urban, high-rapport cultural vernacular
