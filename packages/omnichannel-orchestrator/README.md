# Omnichannel Orchestrator (`omnichannel-orchestrator`)

Core dialogue state machine, microsecond latency profiler, and multi-tenant conversational routing engine.

## Features
- **Dynamic Slot Extraction**: Extracts date, time, stylist, service, and intent from conversational transcripts.
- **Microsecond Latency Profiler**: Instruments STT, LLM TTFT, RAG vector lookup, and TTS synthesis.
- **Tenant Isolation**: Directs utterances to tenant-isolated knowledge bases and booking rules.

## Installation
```bash
pip install omnichannel-orchestrator
```
