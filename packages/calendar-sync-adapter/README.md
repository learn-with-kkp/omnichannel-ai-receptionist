# Calendar Sync Adapter (`calendar-sync-adapter`)

Two-way Google Calendar synchronization, OAuth2 slot availability calculator, and conflict resolver.

## Features
- **Real-Time Free/Busy Matrix**: Queries Google Calendar `freeBusy.query` in real time.
- **Duration-Aware Slot Booking**: Automatically reserves 30m–180m continuous calendar blocks.
- **2-Way Synchronization**: Automatically cancels or reschedules Google Calendar events when changed via voice or social chat.
