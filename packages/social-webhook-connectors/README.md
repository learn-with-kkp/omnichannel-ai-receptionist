# Social Webhook Connectors (`social-webhook-connectors`)

Multi-platform asynchronous webhook connectors for WhatsApp Business, Facebook Messenger, Instagram Direct, LinkedIn, Telegram, Twitter/X, and Reddit.

## Supported Channels
- **Meta Graph API**: WhatsApp Cloud API, Messenger Webhooks, Instagram Messaging.
- **Professional Networks**: LinkedIn Member Message webhook.
- **Social Platforms**: Telegram Bot API, Twitter/X Account Activity API, Reddit Direct Messaging.
